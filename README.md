# Machine Learning Bootcamp

A hands-on machine learning bootcamp. You work on your own laptop, with no cloud services.

## Syllabus

### Day 2: [Unsupervised learning](02-unsupervised-learning/)

Find two leaky columns, group the same customers, flag odd rows, and suggest products. The form has a Segments tab and a Recommendations tab. Work in `02-unsupervised-learning/`.

### [Reinforcement learning](03-reinforcement-learning/)

Play a four-machine game in NumPy. If you finish early, there is a small grid. Work in `03-reinforcement-learning/`.

### Day 3: [Deep learning](04-deep-learning/)

Train a small neural net on churn, then a small CNN on product images. Log one run in MLflow. The form has a churn tab and an image tab. Work in `04-deep-learning/`.

### Day 4: [MLOps reproducibility](05-mlops-reproducibility/)

Version the Fresh and Good churn check. The form loads a model by registry alias and customer features by id. Work in `05-mlops-reproducibility/`.

### Day 5: [MLOps pipelines](06-mlops-pipelines/)

Run the churn training tasks in order, with a gate before the alias moves. The form scores a customer and shows a drift check. Work in `06-mlops-pipelines/`.

### Day 6: [Capstone](07-capstone/)

Demo in 8 minutes. The form in that folder scores a customer, shows drift, and can look a customer up in Feast. Work in `07-capstone/`.
